## SPEC RE (workflow wf_f04525bc, 4 agents, verifie static+live)

### Desequiper — CZ 0x00AB (CZ_REQ_TAKEOFF_EQUIP)
- Paquet **4 octets** : `{u16 0x00AB, u16 index}`. `index` = **invIndex = entree equip +0x04 VERBATIM** (le serveur fait `RFIFOW(fd,2)-2`, l'offset +2 est deja dans la valeur stockee).
- Serveur : `clif_parse_UnequipItem` (moonlight clif.cpp:13748) -> `pc_unequipitem(sd,index,1)`. packetdb `parseable_packet(0x00ab,4,...,2)`.
- Envoi = **raw via `Bourgeon::Instance().SendPacket(pkt,4)`** (comme shop 0xc8 qui marche live -> l'obfuscation eventuelle est geree par SendPacket). Alternative native : `CMode::SendMsg` (FUN_00c86740, vtbl+0x18 du CMode `FUN_00a75340(0x1213338)`) msg 0x14 avec (slot, isCostume) — plus lourd, inutile.

### +Stat — CZ 0x00BB (CZ_STATUS_CHANGE)
- Paquet **5 octets** : `{u16 0x00BB, u16 statType, u8 amount}`. Pour +1 : amount=1.
- statType : STR=**0x0D** AGI=0x0E VIT=0x0F INT=0x10 DEX=0x11 LUK=0x12.
- Serveur `pc_statusup` re-valide tout (bad request inoffensif).
- **Gate client** : afficher/activer le bouton +stat SSI `0 < raise_cost[i] <= status_point`. raise_cost STR..LUK @ **0x015fba3c + i*4**, status_point @ **0x015fb9f4**.
- Envoi = raw `SendPacket(pkt,5)` (ou dispatcher cmd 0x1e via g_UICommandDispatcher 0x0121333c vtbl[6], = ce que fait le natif).

### Lecture d'un slot equipe — IN-PLACE (aucun appel C++, aucune fuite)
Table equip = **`session(0x015fa3c0) + base + slot*0xf8`** ; base = **0x17d0** (normal) / **0x2b30** (costume) / 0x2180 (shadow) / 0x34e0 (costume shadow). slot 0..9. Layout entree (type ItemSkillInfo 0xf8) :
- `+0x00` type · **`+0x04` invIndex** (index serveur, a envoyer pour unequip) · `+0x08` location (masque EQP) · `+0x0c` flag · **`+0x10` present** (==1) · cartes `+0x1c/+0x20/+0x24/+0x28` · **`+0x2c` resname** (std::string, SSO MSVC : cap@+0x40, ptr = cap>15 ? *(char**)(+0x2c) : (char*)(+0x2c) ; **nameid = atoi(resname)**) · 2e string @+0x44 · valid `+0x5c`(byte) · **refine `+0x60`** · **viewId `+0x70`** · grade enchant `+0x88`(u16).
- **Slot occupe** ⇔ `invIndex(+0x04)!=0 && *(+0x10)==1`.
- **Lire l'entree SOURCE en place** (pas via les lecteurs FUN_00d59b90/FUN_00d800b0 qui COPIENT + creent 2 std::string a detruire). SEH-garder les reads.
- Mapping slot#->location : 0=coiffe HAUT(0x100), 1=arme(0x2), 2=cape(0x4), 3=acc1(0x8), 4=armure(0x10), 5=bouclier(0x20), 6=chaussures(0x40), 7=acc2(0x80), 8=coiffe MID(0x200), 9=coiffe BAS(0x1), 15=munition(0x8000, general seul). (0/1/2/5/8/9 confirmes code ; 3/4/6/7 = enum std ; au besoin lire location +0x08 et placer par bit.)
- Icone/nom par nameid = pattern shop (BuildIconPath 0x00d5a720 + TexMgr 0x00a90350 ; DescDbLookup 0x006a0d40 + DescDb 0x01255130, name=*(rec+4)). Desc = MakeWindow(0xc)+OnMsg 0x18 (cashshop_tweaks OpenItemDesc, avec nameid/viewId/location).
