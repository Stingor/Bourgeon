# Journaux de chantier

Histoire détaillée des chantiers de Bourgeon : décisions datées, essais, impasses, mesures.
Un fichier par chantier, nommé comme la fiche de mémoire qui le résume (`<slug>.md`).

La fiche de mémoire ne garde que l'ÉTAT courant et les règles à ne pas oublier ;
tout ce qui est de l'ordre du récit vit ici. Les relevés de RE stabilisés sont dans `docs/*_re.md`.
